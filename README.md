# 飞行检查单编写与校验工具（sologsb-1030）

用于按飞行阶段编写、校验、复核和冻结操作检查单。项目实现完整的数据模型、本地持久化、版本控制、快捷键、拖拽排序、校验、修订差异与打印导出。

## 功能

- 阶段与检查项：维护飞行阶段、挑战语、预期回应、关键标记、前置条件和异常处置。
- 快速录入：可使用 `/` 聚焦挑战语，`Cmd/Ctrl+Enter` 新增检查项，`Alt+↑/↓` 调整当前项位置。
- 拖拽排序：检查项可拖动并跨阶段移动，阶段也可调整先后顺序。
- 发布校验：
  - 重复挑战语与高频回应；
  - 缺少挑战语或预期回应；
  - 自引用、已删除或顺序不可达的前置条件；
  - 飞行阶段顺序异常；
  - 空阶段提示。
- 发布流程：编辑中 → 复核中 → 冻结；存在阻断错误时不能提交复核或冻结。
- 修订控制：冻结后可创建新修订；冻结快照保留阶段、检查项、时间和复核说明。
- 版本差异：可选择当前版本或任意冻结版本作为基准与比较版本，显示新增、删除、修改和阶段调整。
- 离线交接合并：
  - 机长 / 副驾驶平板各自导出 `.fchk.json` 现场改动包，包内嵌同一冻结底本快照与来源标记，回基地完全离线三方合并；
  - 不同检查项直接并入；挑战语、回应、前置条件出现两套值时进入**待决项**，复核人可选用任一侧或给定稿值，全部选定后候选稿才能写入并进入复核稿；
  - 一方改、另一方删的**改删冲突**、引用已删除检查项的**悬空前置条件**、所属阶段缺失的检查项进入**待确认区**，支持保留 / 删除、改绑 / 移除 / 并入其他阶段；
  - 关键标记、异常处置、阶段归属等非阻断字段按最近修改时间自动取值；合并结果逐字段标注来源（机长 / 副驾驶 / 复核人 / 双方一致）；
  - 阶段顺序调整与前置条件可达性对候选稿**即时重算**，改删关联项在对方决定后自动重算；
  - 合并会话随浏览器持久化，交接中断可随时继续；v1 旧草稿打开时自动升级到 v2 后也能参与合并。
- 键盘与历史：支持撤销、重做、手动保存，最近 40 次编辑可回退。
- 离线保存：所有数据写入浏览器 `localStorage`。
- 只读预览与打印：提供对话框预览、浏览器打印/PDF，以及独立打印版 HTML 导出。

## 技术栈

- React 19
- TypeScript 5
- Radix Themes
- Vite 7

## 开发

```bash
npm install
npm run dev
```

开发服务器监听 `0.0.0.0`。宿主机正式端口由根目录 `docker-compose.yml` 映射为 `10030:80`，源码不硬编码宿主端口。

## 类型检查与生产构建

```bash
npm run typecheck
npm run build
npm run preview
```

合并引擎的离线场景验证（三方并入、待决、改删、悬空前置、顺序/可达重算、断点会话）：

```bash
node scripts/merge-scenarios.mjs
```

生产文件输出到 `dist/`。

## Docker

```bash
docker build -t sologsb-1030 .
docker run --rm -p 10030:80 sologsb-1030
```

多阶段镜像构建完成后由 nginx 监听容器 `80`，只提供静态前端资源。

## 数据说明

浏览器存储键为 `sologsb-1030-workspace-v1`（内部 `schemaVersion: 2`，v1 草稿首次打开自动迁移），主题偏好使用 `sologsb-1030-theme`，本机机长/副驾驶身份使用 `sologsb-1030-device-role`。当前版本内置 C172 示例检查单及两个历史冻结版本。离线交接改动包扩展名为 `.fchk.json`，内嵌冻结底本快照，可在无网络环境直接导入合并。
